# ISM3232 - Module 2: zsh Navigation and File Operations

## Commands Practiced

| Command        | What it does                            |
|----------------|-----------------------------------------|
| pwd            | Prints the current working directory    |
| ls             | Lists visible files and folders         |
| ls -la         | Lists all files including hidden ones   |
| cd | Changes the current directory |
| cd .. | Moves up one directory |
| tree -L 2 | Shows the folder structure two levels deep |
| touch | Creates a new empty file |
| echo | Writes or displays text |
| cat | Displays the contents of a file |
| head -1 | Displays the first line of a file |
| cp | Copies a file |
| mv | Moves or renames a file |
| code | Opens a file in VS Code |
| code . | Opens the current folder as a VS Code workspace |
| python3 | Runs a Python file using Python 3 |
| rm | Permanently deletes a file |

## Week 3: Virtual Environments and .zshrc

## Commands Practiced

| Command | What it does |
|---------|--------------|
| python3 -m venv .venv | Creates a Python virtual environment |
| source .venv/bin/activate | Activates the virtual environment |
| which python3 | Shows which Python installation is being used |
| pip list | Lists installed Python packages |
| pip install pytest ruff | Installs pytest and ruff |
| pip freeze > requirements.txt | Saves installed packages to requirements.txt |
| cat requirements.txt | Displays the contents of requirements.txt |
| deactivate | Exits the virtual environment |
| source ~/.zshrc | Applies changes made to the .zshrc file |
| ll | Lists all files including hidden ones |
| gs | Runs git status |
| mkcd | Creates a new directory and moves into it |
